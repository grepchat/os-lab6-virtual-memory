# Исследование виртуальной памяти ОС Windows

Практическое занятие 6. Приложение WinForms на C# (.NET 9, x64).

| Вкладка | Что делает |
|---|---|
| 6.2.1 GetSystemInfo | Архитектура процессора, размер страницы, границы адресов приложения, число процессоров, гранулярность выделения, уровень и модификация процессора |
| 6.2.2 GlobalMemoryStatus | Загрузка памяти, физическая память, файл подкачки, виртуальная память; периодическое отслеживание |
| 6.2.3 VirtualQuery | Расшифровка `MEMORY_BASIC_INFORMATION` по адресу, обход регионов, карта адресного пространства, демонстрация `VirtualAlloc` / `VirtualFree` |

## Запуск

```bash
dotnet run --project VirtualMemoryLab
```
